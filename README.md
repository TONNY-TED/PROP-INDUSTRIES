# Prop Industries - Web Platform

Prop Industries is a modern technology and innovation company platform built to showcase enterprise software development, web engineering, IoT automation systems, digital branding, and ICT training.

---

## 🛠 Developer & Media Guide

### Tech Stack
- **Framework:** React 18+ (TypeScript)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4.0
- **Animations:** Motion (formerly Framer Motion)
- **Icons:** Lucide React

### Local Images & Asset Folder Structure
To place custom logos, hero slides, or portfolio images, simply drop your files into the `public/images/` directory:

```
public/
└── images/
    ├── prop-industries-logo.png   (Primary company logo)
    ├── hero/                      (Hero slider images)
    │   ├── slide1.jpg
    │   ├── slide2.jpg
    │   └── slide3.jpg
    └── gallery/                   (Project showcase images)
        ├── carequeue.jpg          (CareQueue hospital app)
        ├── prop-website.jpg       (Prop Industries website)
        ├── smart-watch.jpg        (Smart Health Watch IoT)
        ├── branding.jpg           (Branding & design)
        ├── training.jpg           (Computer training)
        └── erp.jpg                (Business software)
```

### Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run development server:**
   ```bash
   npm run dev
   ```
   The application runs at `http://localhost:3000`.

3. **Build for production:**
   ```bash
   npm run build
   ```
