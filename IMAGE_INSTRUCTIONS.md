# Image Placement Instructions

To make your images work, please place your image files in the following folders inside your project's `public` directory:

## 1. Hero Slider Images
Folder: `public/images/hero/`
Filenames needed:
- `slide-1.jpg`
- `slide-2.jpg`
- `slide-3.jpg`
- `slide-4.jpg`
- `slide-5.jpg`
- `slide-6.jpg`
- `slide-7.jpg`
- `slide-8.jpg`
- `slide-9.jpg`
- `slide-10.jpg`

## 2. Gallery Images
Folder: `public/images/gallery/`
Filenames needed:
- `zantchito-1.jpg` to `zantchito-6.jpg`
- `girls-1.jpg` to `girls-3.jpg`
- `frmt-1.jpg` to `frmt-3.jpg`
- `training-1.jpg` to `training-6.jpg`
- `internship-1.jpg` to `internship-4.jpg`
- `engineering-1.jpg` to `engineering-8.jpg`

## 3. Services Background
Folder: `public/images/`
Filename needed:
- `services-bg.jpg`

---
Note: You can use `.png` or `.webp` as well, but you will need to update the file extensions in the code (Gallery.tsx, Hero.tsx, Services.tsx) to match.
